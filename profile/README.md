# PetFed

India's biggest pet festival, now going multinational. PetFed brings pet parents,
brands and vets together at events across the country, with an app for tickets,
rewards and pet profiles.

### What we build
- **PetFed app** (iOS and Android): event tickets, rewards wallet, pet profiles
  and Free Desi adoption applications
- **Admin console**: the operations dashboard for events, customers and payments
- **Merchant dashboard**: sales and settlement for stall partners
